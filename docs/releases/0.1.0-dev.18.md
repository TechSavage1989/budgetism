# 0.1.0-dev.18 development preview

Builds on user-confirmed dev.17 with a provider-independent fictional bank source pipeline and one Needs Review inbox. Connections provides reviewed account mapping, distinct recorded/reported/available balances, refresh timestamps/status, manual refresh, repeat/interruption checks and reconnect/disconnect preserving history.

Pending records stay outside balances. Explicit predecessor identities replace pending authorizations with posted sources. Complete pages, source changes, balances and checkpoints commit atomically; retries and reordered repeated batches do not duplicate. Posted items enter the ledger only after review, with exact integer accounting, existing-entry matching, paired transfers/card payments, preserved user metadata, explicit removals and protected reconciliation conflicts. Schedule matching uses existing reciprocal links without reposting.

First confirmed mapping upgrades financial schema to 8 only after backup/fictional-account consent. Viewing existing workspaces makes no upgrade. All prior financial collections, optional password, encryption, device keys, imports, rules, backups and updater behavior are retained. Older builds cannot open an upgraded workspace.
