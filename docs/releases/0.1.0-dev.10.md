# Budgetism 0.1.0-dev.10

Add a read-only Reports destination: historical date/account filters, income and expenses, category contributions, monthly trends and recorded account balances. Support explicit desktop CSV exports with unencrypted-data confirmation and safe text encoding. No financial schema, encryption or dependency change. Preserve dev.9 reconciliation locks and all previous functionality.

Full hosted tests, Windows/web compilation, native report preservation and the exact-package Defender scan must pass before delivery. This is an unsigned development preview, not a release or production approval. No server, bank integration, synchronization or updater installation is added. See [reports](../REPORTS.md), [validation](../VALIDATION.md) and [desktop testing](../WINDOWS_TESTING.md).
