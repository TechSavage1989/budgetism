# Budgetism 0.1.0-dev.17

Daily-use Home with recorded-through-today totals and quick actions, direct Settings tools, scrollable desktop navigation and a narrow-screen More drawer. Local transaction entry adds searchable selectors, local history-only payee completion and explicit Save and add another with cleared financial details and safe retry identities.

No schema/storage/security migration. All prior calendars, rules, imports, reconciliation and backups are retained. Bank connectivity, synchronization and update installation are not enabled. Hosted validation and exact-package scan are required before delivery. See DAILY_USE.md and VALIDATION.md.
