# Budgetism 0.1.0-dev.13

Add categorization batch history and explicit, reviewed category-only undo. Show original/applied/current categories and original rule versions from the existing encrypted audit, including dev.11/dev.12 batches. Undo requires a reason and complete unchanged, unreconciled records; append history rather than replacing it. Preserve financial values, counts, receipts, schedule links, statements and saved rule definitions.

No new schema, encryption, backup format or dependency. No automatic reapplication, partial undo or general financial rollback. Hosted validation and the exact-package scan are required before delivery. This is an unsigned development preview, not a release or production approval. See [history](../CATEGORY_HISTORY.md), [validation](../VALIDATION.md) and [Windows testing](../WINDOWS_TESTING.md).
