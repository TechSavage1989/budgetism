# Budgetism 0.1.0-dev.16

Usability-focused calendar controls for schedule, occurrence, statement, rule and register dates. Add Today/optional-clear actions, transaction Today/Yesterday, inclusive date-range presets and a visual budget month/year selector. Manual entry remains optional. Preserve cancellation, immutable schedule anchors, reconciliation locks and rule-review invalidation. No financial migration or storage change.

Full hosted validation and exact-package Defender scans remain required before delivery. Development artifacts only, not a release/tag or production approval. See [date controls](../DATE_CONTROLS.md), [Windows testing](../WINDOWS_TESTING.md), [validation](../VALIDATION.md) and [next usability priorities](../USABILITY_ROADMAP.md).
