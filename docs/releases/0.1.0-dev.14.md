# Budgetism 0.1.0-dev.14

Saved encrypted CSV import profiles with header-name mappings, separators, date/sign conventions and default categories. Explicit application supports reordered columns, rejects missing/ambiguous mapped headers and never changes the destination account. Profiles can be updated, renamed, archived and restored. Saving settings does not import transactions; existing duplicate review remains mandatory.

The first profile save requires backup/consent for financial schema 7. Older apps cannot open the upgraded workspace. Existing records, rule history, statement protections and optional-password behavior are preserved. Hosted validation and exact-package scan are required before delivery. Development artifacts only, not a production release. See [profiles](../IMPORT_PROFILES.md), [validation](../VALIDATION.md) and [Windows test](../WINDOWS_TESTING.md).
