# Budgetism 0.1.0-dev.14

Saved encrypted CSV import profiles with header-name mappings, separators, date/sign conventions and default categories. Explicit application supports reordered columns, rejects missing/ambiguous mapped headers and never changes the destination account. Profiles can be updated, renamed, archived and restored. Saving settings does not import transactions; existing duplicate review remains mandatory.

The first profile save requires backup/consent for financial schema 7. Older apps cannot open the upgraded workspace. Existing records, rule history, statement protections and optional-password behavior are preserved. All five jobs passed in [run 40801825492](https://github.com/TechSavage1989/budgetism/actions/runs/40801825492), including native restart tests and exact ZIP/extracted Defender scans. Independent package verification passed. The app remains unsigned and manual profile testing is pending. Development artifacts only, not a production release.
